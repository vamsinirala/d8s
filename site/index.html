D8s

Compare Kubernetes resources across environments. Find the config drift between dev, staging and prod before it finds you.

Try the live demo View on GitHub

What it does

Multi-environment comparison

Pick any set of environments — any mix of clusters and namespaces — and see what's present, what's missing, and how many fields differ for every resource kind.

Field-level diff

Drill into any resource for a path-by-path comparison, filtered by probes, resource limits, env vars, volumes, images or config data.

Image version drift

One table showing every deployment's image tag across environments, so version drift is obvious without opening a single resource.

Deployment bundles

See everything a deployment references and everything referencing it back — including dangling references pointing at resources that don't exist.

Secrets stay secret

Secret values are hashed server-side before they reach the browser. You can tell that two secrets differ; you never see their contents.

Runs entirely local

Uses your existing kubeconfig and auth plugins. Nothing is uploaded anywhere — there's no backend service and no account.

Get started

# Download the latest release bundle, then:
tar -xzf d8s-<version>.tgz
cd d8s-<version>
./start.sh          # start.cmd on Windows

Needs Node.js 20+ and a working kubeconfig. Or run from source: npm install && npm run dev.

Note: D8s runs on your machine, not here. The demo above uses sample data so you can explore the interface — the real tool needs local access to your kubeconfig and clusters.
